# 🏦 AI SQL Assistant — Natural Language Banking Queries

[![CI](https://github.com/AfridaMehanaz/ai-sql-assistant/actions/workflows/ci.yml/badge.svg)](https://github.com/AfridaMehanaz/ai-sql-assistant/actions/workflows/ci.yml)

An LLM agent that turns plain-English questions into safe, read-only SQL,
runs them against a banking database, and answers in natural language —
with automatic self-correction when a query fails.

> Demo data is fully synthetic ("Meridian Bank"). No real customer data.
